# AI Job Hunter

AI Job Hunter is a React application that helps streamline the software job search process. It allows users to discover jobs, save opportunities, analyze resumes, generate cover letters, and track applications in one place.

## Features

* Dashboard
* Job Listings
* Saved Jobs
* AI Agent
* Resume Analyzer
* Cover Letter Generator
* Search Hub
* Application Tracker
* Settings

## Built With

* React
* Vite
* JavaScript
* Tailwind CSS

## Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/AI-Job-Hunter.git
cd AI-Job-Hunter
npm install
npm run dev
```

Replace `YOUR_USERNAME` with your GitHub username.
